# Code of Conduct

This project follows the **Contributor Covenant Code of Conduct v2.1**.  
Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting
If you observe unacceptable behavior, please report it to **<your-email@example.com>**.  
If you prefer, you can also open a private GitHub issue and mark it clearly as “Code of Conduct”.

We will review all good-faith reports and respond promptly while respecting confidentiality.

## Enforcement
Project maintainers may take any action deemed appropriate, including warnings or account bans, to maintain a welcoming environment.
