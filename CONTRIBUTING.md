# Contributing

- **Branching:** `feature/*`, `fix/*`, `chore/*`
- **Commits:** Conventional Commits (e.g., `feat: add s3 list-objects prefix`)
- **PRs:** Keep them small. Use the PR template. Note risk & rollback.

## Local checks
Format, lint, and test locally to match CI:
black .
flake8 .
pytest -q
